🚀 Week 10: JavaScript Fundamentals & Control Flow
Welcome to the Week 10 update of my web development journey! This week, I transitioned from building static layouts to creating interactive logic using JavaScript. I focused on setting up a professional local development environment and understanding how programs make decisions.
🛠️ Key Learning Objectives
Local Development: Moving from online editors to a professional workflow using VS Code and Live Server.
Dynamic Logic: Understanding how variables, data types, and control flow allow a website to "think."
Debugging: Learning to use the browser console to track down syntax and logical errors.
💻 Technical Skills Mastered
1. The Local Workflow
I integrated my HTML and JavaScript files locally.
Pro-Tip: Always place the <script src="script.js"></script> tag at the very bottom of the <body> to ensure the HTML loads before the logic runs.
2. Variables & Data Types
I practiced organizing data into different "containers" based on their purpose:
const: For values that stay permanent (like a user's ID).
let: For values that change (like a score or a timer).
Data Types: Mastered the use of Strings, Numbers, and Booleans.
3. Control Flow (Decision Making)
The core of this week was learning how to use if-else statements and logical operators (&&, ||).
Example Logic implemented:
let currentHour = new Date().getHours();
if (currentHour < 12) {
    console.log("Good morning!");
} else if (currentHour < 18) {
    console.log("Good afternoon!");
} else {
    console.log("Good evening!");
}
🔍 Debugging Wins
This week, I learned to distinguish between:
Syntax Errors: Finding the "missing bracket" or "typo" that breaks the code.
Logical Errors: Fixing code that runs but doesn't behave as expected (e.g., checking conditions in the wrong order).
